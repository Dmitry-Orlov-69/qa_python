# Описание тестов для класса BooksCollector

#### test_add_new_book 
Этот тест проверяет возможность добавления новой книги в коллекцию. Проверяются два случая: 
1. Добавление книги с допустимым названием («Война и мир»). 
2. Добавление книги с названием, превышающим допустимую длину (41 символ).
В первом случае книга должна успешно добавиться, а во втором — нет.

#### test_set_book_genre
Этот тест проверяет, что метод set_book_genre корректно устанавливает жанр для заданной книги. В тесте используются разные комбинации названий книг и жанров, чтобы убедиться, что после вызова метода get_book_genre возвращает ожидаемый жанр.

#### test_get_book_genre
Тест test_get_book_genre проверяет, что метод get_book_genre корректно возвращает жанр книги, который был установлен в словаре books_genre. В этом тесте мы добавляем новую книгу, задаём её жанр напрямую через словарь (без использования метода set_book_genre), а затем проверяем, что метод get_book_genre возвращает именно тот жанр, который мы задали. Это помогает убедиться, что получение жанра книги работает правильно.

#### test_get_books_with_specific_genre 
Этот тест проверяет получение списка книг по определённому жанру. Для этого: 
1. Добавляются книги («Гарри Поттер», «Мастер и Маргарита»). 
2. Устанавливаются жанры для книг («Фантастика»). 
3. Получаются книги по указанному жанру и проверяется наличие добавленных книг в списке.

#### test_get_books_genre 
Проверка получения словаря с жанрами всех книг в коллекции. Для примера добавляется книга «Мастер и Маргарита» с жанром «Фантастика» и проверяется, что метод возвращает корректный словарь.

#### test_get_books_for_children 
Тест проверяет получение списка детских книг. Для этого: 
1. Добавляются детские книги («Кот в сапогах», «Приключения Тома Сойера»). 
2. Устанавливаются соответствующие жанры («Мультфильмы»). 
3. Проверяется наличие добавленных детских книг в полученном списке.

#### test_add_book_in_favorites
Этот тест гарантирует, что добавление книги в список избранного работает корректно. Для нескольких названий книг проверяется, что после добавления книги в избранное, она присутствует в списке избранных книг.

#### test_delete_book_from_favorites
Тест направлен на проверку корректности удаления книги из списка избранного. Сначала книга добавляется в избранное, а затем удаляется. После этого проверяется, что книга больше не присутствует в списке избранных.

#### test_get_list_of_favorites_books 
Этот тест проверяет получение списка избранных книг: 
1. Книга добавляется в коллекцию («Унесённые ветром»). 
2. Книга добавляется в список избранных. 
3. Получается список избранных книг и проверяется, что он содержит ожидаемую книгу.
